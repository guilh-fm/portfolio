# Projetos Livres

Esta pasta reúne projetos feitos para estudo, prática e aprendizado fora do contexto direto do estágio ou da faculdade.

## Projetos

### Assistente de Estudos

Projeto em Python criado para estudar IA generativa aplicando os conceitos em um assistente de estudos.

O projeto passa por uma evolução em etapas:

- chamada de LLM via API;
- engenharia de prompt;
- uso de LangChain;
- testes com RAG;
- interface web com Streamlit.

### Gerador de Carteirinhas DBB

Projeto em Python criado para gerar carteirinhas de membros da Diáspora Beninense do Brasil.

O programa lê uma planilha Excel, busca fotos e assinaturas pelo ID de cada pessoa e gera um PDF por membro com frente e verso da carteirinha.
