# Portfólio de Projetos

Este repositório reúne alguns projetos que desenvolvi durante minha formação e minha experiência profissional inicial.

A ideia é manter os códigos organizados por contexto, com uma explicação simples do problema resolvido, das tecnologias usadas e do que foi aprendido em cada projeto.

## Projetos de Estágio

### PFICA - Formulários CLARO/ALGAR

Aplicação em Python criada para automatizar o preenchimento de formulários de interconexão das operadoras Claro e Algar.

O programa lê uma planilha Excel com os dados das áreas locais, preenche um modelo Word com os marcadores correspondentes e permite converter os documentos gerados para PDF.

### PFOI - Formulários OI

Aplicação em Python criada para automatizar o preenchimento de formulários de interconexão da operadora OI.

O programa lê uma planilha de pedido, substitui marcadores em um modelo Excel e gera um formulário preenchido para cada área local.

## Projetos Livres

### Assistente de Estudos

Projeto em Python e Streamlit criado para estudar IA generativa de forma prática.

O projeto evolui em etapas: chamada de LLM via API, engenharia de prompt, uso de LangChain e testes com RAG usando PDFs como fonte de consulta.

### Gerador de Carteirinhas DBB

Projeto em Python criado para gerar carteirinhas de membros da Diáspora Beninense do Brasil.

O programa usa uma planilha Excel, fotos, assinaturas e QR Codes para montar PDFs individuais com frente e verso da carteirinha.

## Observação

Os arquivos de exemplo foram mantidos apenas para demonstrar o funcionamento dos programas. Dados reais ou sensíveis não devem ser colocados neste repositório.
